Zoro - Privacy Policy

Last updated: 1 October 2026

What Zoro is

Zoro is a personal desktop assistant that runs on the computer of the Zoro NutriDiet team. It is used only with the team's own accounts and is not offered to the public.

YouTube API Services

Zoro uses YouTube API Services to upload the owner's own videos to the owner's own YouTube channel and to read that channel's details and analytics. By using Zoro you are agreeing to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is also subject to the Google Privacy Policy.

Google data Zoro accesses

With the owner's permission, Zoro uses these Google APIs:

  • YouTube Data API (youtube.upload, youtube.readonly, youtube.force-ssl): to read the owner's channel details and to upload the owner's videos, thumbnails and captions.
  • YouTube Analytics API (yt-analytics.readonly): to read performance reports for the owner's own channel.
  • Google Calendar API (calendar.events): to add and read the owner's content schedule events.

How the data is used

Data is used only to carry out tasks the owner asks for, such as publishing a video or preparing a performance report.

Storage

OAuth tokens and all data stay on the owner's own computer. Tokens are kept in local protected storage. No data is stored on any Zoro server. Zoro does not use cookies or tracking, and stores no information on any other user's device.

Channel and analytics data read through YouTube API Services is kept only as long as needed for the owner's reports and is refreshed or deleted within 30 days, as the YouTube API Services Developer Policies require.

Sharing

Zoro does not sell or share Google user data. Text or media may be sent to the AI model provider chosen by the owner (for example Google Gemini) only to process the owner's request.

Google API Services User Data Policy

Zoro's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the Google security settings page at security.google.com/settings/security/permissions (also at myaccount.google.com/permissions). Deleting the local token file also removes Zoro's access, and the owner can ask for any stored data to be deleted at the contact address below.
