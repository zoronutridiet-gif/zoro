Zoro - Terms of Service

Last updated: 2 October 2026

1. What Zoro is

Zoro is a private desktop assistant. I, Dr. Srinivas Patel Punyala (Zoro NutriDiet), am its only user. It runs on my own Windows laptop and helps me prepare and publish evidence-based nutrition videos on my own YouTube channel. Zoro is not offered, sold or licensed to anyone else.

2. YouTube Terms of Service

Zoro uses YouTube API Services. By using Zoro, you agree to be bound by the YouTube Terms of Service.

3. Google Privacy Policy

Information accessed through YouTube API Services is handled as described in the Zoro Privacy Policy and the Google Privacy Policy. Zoro's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Acceptable use

  • Zoro uploads only to my own YouTube channel, and only content I made or have the rights to publish.
  • Zoro publishes to YouTube only through the official YouTube Data API. It has no YouTube Studio browser mode and does not use any third-party upload service for YouTube.
  • For a manual upload, Zoro opens youtube.com/upload in my normal web browser and I upload the video by hand. Zoro does not control that page.
  • When a chat, agent task or workflow gets data from YouTube API Services, Zoro processes that data with open models hosted by Groq. My own spoken words in voice conversations go to Google's Gemini Live API. The Zoro Privacy Policy gives the details and lists the known exceptions.
  • Zoro reads other channels only as public data, for research. It never takes any action on them.
  • My videos follow the YouTube Community Guidelines, including the medical misinformation policy and the rules for disclosing altered or synthetic content.
  • Zoro does not manipulate views, likes, comments or subscribers.
  • Zoro has no code that scrapes YouTube pages or downloads videos or captions. It gets YouTube API data only through the official YouTube API Services. Separately, it can send links of public videos to Google's Gemini API for a summary, as the Zoro Privacy Policy describes. Its browser agent and page-reading tools are blocked from YouTube pages. One general tool for calling web APIs does not block YouTube addresses yet.

5. Revoking access

The Disconnect button in Zoro revokes the token at Google, deletes the local tokens and deletes the stored YouTube data that Zoro's 30-day job covers. It also rebuilds the local backups by the same rules. If revoking at Google fails, Zoro shows a warning and a link to the Google permissions page. A separate "Delete stored YouTube data" button deletes the same data even when Zoro is not connected to Google. Some copies are not yet covered. The Zoro Privacy Policy lists them. Google account access can also be revoked at any time at security.google.com/settings/security/permissions.
