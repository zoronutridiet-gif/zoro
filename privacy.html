Zoro - Privacy Policy

Last updated: 2 October 2026

What Zoro is

Zoro is a private desktop assistant. I, Dr. Srinivas Patel Punyala (Zoro NutriDiet), am its only user. It runs on my own Windows laptop and helps me make and publish evidence-based nutrition videos on my own YouTube channel. Zoro is not offered to anyone else.

YouTube API Services

Zoro uses YouTube API Services. By using Zoro, you agree to be bound by the YouTube Terms of Service. Information that Zoro gets through YouTube API Services is also subject to the Google Privacy Policy.

Google sign-in and scopes

Zoro signs in to one Google account, my own, through an OAuth 2.0 Desktop client. It asks for these scopes:

  • youtube.upload: to upload my videos and set their thumbnails.
  • youtube.readonly: to read my own channel details and my video statistics.
  • youtube.force-ssl: to upload subtitle and caption tracks to my videos, to check which tracks they already have, and to read comments on my own videos.
  • yt-analytics.readonly: to read analytics for my own channel.
  • calendar.events: to add and read events in my content calendar. This is not YouTube data.

Publishing

Zoro publishes to YouTube only through the official YouTube Data API. It uploads a video when I ask it to, or on a schedule I set up. By default, each upload carries the altered or synthetic content disclosure (containsSyntheticMedia) and is marked as not made for kids.

For a manual upload, Zoro opens youtube.com/upload in my normal web browser and I upload the video by hand. Zoro does not control that page.

Zoro has no YouTube Studio browser mode and does not use any third-party upload service for YouTube. Zoro's general web tools are blocked from opening or fetching YouTube pages.

Comments

Zoro reads comments only on my own videos. A Groq-hosted AI model groups the viewer questions so I can plan videos that answer them. Zoro never posts, edits or deletes comments.

Public research data

Zoro also uses a YouTube Data API key to read public data: public channel details, public video lists and statistics, search results and trending charts. I use this to study what works on health channels. Zoro does not scrape YouTube, and it never takes any action on other channels.

How the data is used

Zoro uses this data only to do what I ask, such as publishing a video, preparing a performance report or planning content. It does not sell data and does not use it for advertising.

AI processing

In chat, reports and agent tasks, data that Zoro gets from YouTube API Services is processed by open models hosted by Groq. This covers my own channel analytics, my video statistics, the text of public comments on my own videos, and public channel and video statistics. By default, Groq does not keep inference data (see Groq: Your Data).

Zoro uses Groq's free tier, which has rate limits and daily limits. If Groq is unavailable during such a task, Zoro tells me it cannot process the YouTube data right now instead of passing it to another AI.

Voice is the exception. If I ask about my channel in a voice conversation, the spoken answer goes through Google's Gemini Live API.

Zoro may also turn viewer questions into short learning-topic names, such as "iron in spinach", and research those topics later with Gemini or web search.

For other tasks, such as writing scripts or research on sources that are not YouTube, Zoro may use the Google Gemini API. The free tier of the Gemini API may use prompts to improve Google products (see the Gemini API terms).

Separately, when I ask, Zoro may send the link of a public YouTube video to the Gemini API so that Gemini can summarise the video. This happens in a separate task that has not used any data from YouTube API Services. Zoro does not download videos or captions.

Text is sent to an AI model only to carry out my request. It is not sold and is not used for advertising.

Telegram and notifications

If I chat with Zoro through my own Telegram bot, Zoro's replies pass through Telegram. These replies may include my own channel analytics or summaries of viewer questions. If I turn on ntfy, Zoro sends only short notifications to my own ntfy topic.

Storage

Zoro keeps its data on my laptop. OAuth tokens are encrypted with Windows DPAPI, so only my Windows account can read them. API keys are kept in Windows Credential Manager. Other data is kept in local files and a local SQLite database. There is no hosted Zoro server. Zoro's only server listens on 127.0.0.1 on my laptop.

Zoro keeps its last 14 daily backups on my laptop. A backup can contain YouTube data, so that data can stay in a backup for up to 14 days after it is deleted elsewhere.

Sharing

Zoro does not sell Google user data or share it with anyone for their own use. Data leaves my laptop in these cases:

  • Calls to Google's own APIs (YouTube Data API, YouTube Analytics API, Google Calendar API).
  • Text that contains YouTube data sent to open models hosted by Groq, as described above.
  • Text for other tasks, voice conversations, learning topics and links to public YouTube videos sent to the Gemini API, as described above.
  • Replies that pass through Telegram when I chat with Zoro through my own Telegram bot.
  • Short notifications sent to my own ntfy topic, if I turn them on.

How long data is kept

A daily job deletes or redacts the YouTube data Zoro has stored once it is 30 days old. This covers raw files, reports, notes, AI lessons, learning topics taken from viewer questions, agent outputs, and chat messages and workflow checkpoints that contain YouTube data. Backups roll off as described under Storage.

Records of my own uploads (the video IDs and links of videos I uploaded to my channel) are kept until I press Disconnect or "Delete stored YouTube data".

Zoro's skills keep only general lessons about video formats. They contain no exact YouTube statistics.

Google API Services User Data Policy

Zoro's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The Disconnect button in Zoro revokes the token at Google, deletes the local token files and deletes the YouTube data Zoro has stored (backups roll off within 14 days). If revoking at Google fails, Zoro shows a warning and a link to the Google permissions page, where I can remove access myself.

A separate "Delete stored YouTube data" button deletes the stored YouTube data even when Zoro is not connected to Google.

Access can also be removed at any time from the Google security settings page at security.google.com/settings/security/permissions (also at myaccount.google.com/permissions).

Cookies

This website sets no cookies and has no tracking. Zoro keeps my Instagram and Facebook sign-ins in a separate local Chrome profile for posting to those sites. YouTube and Google are not used through that profile; Google access uses the encrypted OAuth token. That profile stays on my laptop and is not shared. Zoro does not place cookies on anyone else's device.
